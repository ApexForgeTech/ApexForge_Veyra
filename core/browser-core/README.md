# Browser Core Track

This directory is reserved for Veyra's future engine-integration layer.

Veyra should be treated as its own browser product. The underlying rendering and runtime backend is an implementation detail, not the product identity.

Planned responsibilities:

- engine evaluation notes
- browser-core integration strategy
- patch and abstraction inventory
- shell-to-engine boundary design
- security hardening hooks
- build instructions for the real browser core
